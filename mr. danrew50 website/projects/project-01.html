North / Form.

A restrained visual system with a stronger contrast underneath.
The idea

North / Form pairs a quiet utility base with one confident accent. The system is designed to feel considered at first glance, then reveal more detail as the viewer moves through it.

01 / Identity board
02 / Editorial detail
03 / Digital application
Approach
Quiet enough to trust. Distinct enough to remember.

The identity establishes a simple rhythm: strong headings, generous fields, precise utility details and one recurring red gesture.

The same language then carries through the website so the brand feels like a single object rather than a collection of pages.
