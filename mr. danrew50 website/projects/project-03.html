Red Signal.

A campaign system with a visible pulse.
The idea

The visual language is intentionally immediate: dark field, red signal, oversized numerals and editorial pacing. The same framework can flex from campaign artwork to a scroll-driven landing page.

01 / Campaign hero
02 / Brand extension

Approach
Use one strong move. Repeat it well.

The campaign avoids a library of competing motifs. One red signal carries the identity, animation and hierarchy.

That makes the system quick to adapt while keeping each touchpoint immediately recognisable.
