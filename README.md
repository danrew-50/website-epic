# Danrew-50 Website, Made by Naman Aggarwal

A polished multi-page static website base designed for rapid client approval and fast final delivery.

## Pages
Home, Work, Project detail (3 studies), About, Services, Branding, Contact, Credits.

## Fast handoff
1. Edit `js/site-config.js` for the client name, mark, tagline, email and social links.
2. Edit `js/projects.js` if project data needs to be centralised.
3. Replace local artwork in `assets/images/` with the client’s real work.
4. Replace the temporary branding files under `assets/branding/` after approval.

## Run locally
Use any static server, for example:

`python -m http.server 8000`

Then open `http://localhost:8000/`.
